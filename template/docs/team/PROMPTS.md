# Старт-промпты

Вставьте нужный промпт первым сообщением в Claude Code, открытый в папке проекта.
Замените `<…>`. Промпты короткие: правила Claude и так прочитает из `CLAUDE.md`.

## Первый запуск (каждый участник, один раз)

```
Я в команде проекта, моя роль — <роль>, мой GitHub — <логин>. Прочитай CLAUDE.md,
.github/team.conf и docs/team/ROLES.md. Запусти scripts/team.sh doctor и помоги исправить,
если что-то не так. Потом коротко скажи, какая у меня зона и с чего начать.
```

## Взять задачу

```
Моя роль — <роль>. Возьми задачу #<номер>: запусти scripts/team.sh start <номер>, прочитай
задачу (gh issue view <номер>), предложи план из 3–6 шагов и жди моего «ок».
Работай только в своей зоне.
```

Если номера ещё нет:

```
Моя роль — <роль>. Покажи свободные задачи моей роли (scripts/team.sh board) и предложи,
какую взять первой.
```

## Закончить задачу

```
Проверь, что всё из «Готово, когда» в задаче выполнено. Затем scripts/team.sh sync,
проверки проекта и scripts/team.sh pr. Заполни в PR «Что сделано» и «Как проверить».
```

## Не успел — передать

```
Я заканчиваю. Запиши передачу: scripts/team.sh note <номер> "…" — что сделано, что
осталось, где проблема, какие файлы трогали. Закоммить сделанное и запушь ветку.
```

## Продолжить чужую задачу

```
Продолжаю задачу #<номер>. Прочитай задачу и последнюю «Передачу» в комментариях,
переключись на её ветку (git switch <ветка>), scripts/team.sh sync и скажи, что осталось.
```

## Владелец: разбить идею на задачи

```
Наша идея: <2–3 предложения>. Срок: <N> часов, нас <N> человек, роли из docs/team/ROLES.md.
Разбей работу на задачи по 1–4 часа так, чтобы роли не правили одни и те же файлы.
Сначала покажи список (роль, название, «готово, когда», файлы), после моего «ок» создай
их через scripts/team.sh task.
```

## Владелец: разобрать PR

```
Посмотри открытые PR (scripts/team.sh board). Для каждого: проверки, дифф, зона, секреты,
конфликты с main. Предложи порядок слияния. Сливать — только после моего «ок» по каждому,
через scripts/team.sh merge <номер>.
```

## QA: прогон демо

```
Пройди сценарий демо из docs/team/HACKATHON.md на свежем main: собери, запусти, проверь
каждый шаг. На каждую поломку заведи задачу (тип bug, метка demo) с шагами повторения.
```
